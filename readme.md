Atividade Agenda 08 : Pesquisa de Satisfação 

Este programa tem como objetivo avaliar nosso atendimento através de uma pesquisa de satisfação do cliente. Inicialmente são requeridos alguns dados de entrada como nome do cliente e idade. Cadastrados os dados pessoas o cliente faz a avaliação da satisfação sendo 1-Excelente, 2- Bom e 3-Ruim. Ao final do programa, é realizado uma soma do total de avaliações com resultado excelente e ruim
